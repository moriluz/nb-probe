# Security

nb-probe scans an application you own. If you find a vulnerability in the tool itself, email hello@neural-breach.com.

Include the version (`nb-probe --version`), the command you ran with secrets removed, and what you expected to happen. Give us a chance to fix it before you describe the issue in public.

Do not use this address to report a bug in someone else's application. The ownership file is an opt-in for your own origin, not an invitation to scan other hosts.
